## 한 줄 총평
**제주 여행에만 제한되지만, 강아지 정보를 미리 입력하면 수동 필터링 없이 자동으로 조건에 맞는 장소를 볼 수 있다는 점이 강점. 다만 데이터 부족과 사용자 후기 부재로 신뢰도가 낮아 결국 네이버 지도나 블로그로 돌아갈 가능성이 높다.**

## 지킬 것 3
1. **강아지 정보 기반 자동 필터링** — 무게, 나이, 소유 물품이 자동으로 반영되는 방식. 네이버 지도보다 한 단계 진화한 경험. (B 상태의 숙소 리스트에서 "칼수 있어요", "삶대 있어요" 태그로 필터 상태가 눈에 보임)
2. **카테고리별 통합 비교** — 홈에서 한눈에 "숙소 26, 식단 34, 카페 26"을 보고, 각 탭에서 전체 리스트를 한화면에서 비교하는 구조.
3. **명확한 동반 조건 표기** — 무게 구간별 가격(1~5kg 1만원, 6~10kg 1.5만원), "싱할 OK", "대형견 OK" 같은 태그로 한눈에 파악 가능.

---

## 바꿀 것 3
1. **데이터 절대 부족** (심함) — 86곳은 너무 적음. 네이버 지도의 "애견동반" 검색 결과만 해도 제주도 숙소/카페만 해도 이보다 많을 것. 앱이 차별성을 갖으려면 최소 500곳 이상 필요. (A-01, A-02, A-03, A-04)
2. **사용자 리뷰·평점 전무** — 앱의 정보를 신뢰할 근거가 없음. "이 펜션에 다녀간 사람의 후기는?" 하는 질문에 답할 수 없음. (A-06, A-07에 리뷰 섹션이 없음)
3. **제주도 외 미지원** — 강아지 동반 여행을 많이 하는 사용자라면 부산, 강원, 경주 등도 다님. 이 앱 하나로는 모든 여행을 커버할 수 없어 결국 다른 앱을 함께 써야 함.

## 다음에 할 단 하나
**전국 확대.** 강아지 정보 기반 필터링과 통합 비교 UI는 잘 만들어졌으므로, 제주만이 아니라 다른 관광지(서울, 부산, 강원, 경주, 전주 등)로 확장하면 한 번이라도 더 열 가능성이 높아짐.

## 다른 관점의 리뷰어라면 놓칠 것 1
**강아지 여러 마리 등록 후 개별 필터링.** 이 사용자는 보리(28kg)와 콩이(17kg)를 등록했을 때(B 상태), 앱이 두 강아지 중 누구의 조건으로 필터링할지, 아니면 둘 다에게 적합한 곳만 보여줄지는 명확하지 않음. 다견 가정의 복잡한 필터링 로직을 고려하면 UX가 더 정교해야 함.
