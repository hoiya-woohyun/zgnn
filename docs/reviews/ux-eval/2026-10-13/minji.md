# 민지(29, 말티즈 '두부' 3kg · 슬링백) — 2026-10-13 평가

> 기기: iPhone 13 에뮬레이션(Playwright) · 카페 투어가 목적인 여행 · 스크린샷은 `shots/minji-*.png`

## 1. 첫인상

첫 화면 맨 위에 "강아지랑 제주 · 반려견 동반 제주 가이드"와 핑크 버튼 "우리 강아지 등록하기 — 숙소 31곳 중 7kg 아이는 21곳, 25kg 아이는 6곳 갈 수 있어요"가 같이 떠서, 우리 애 몸무게 넣으면 갈 수 있는 데 골라 주는 앱이구나 하는 게 3초 만에 들어왔어요.
두부 등록하고 나서는 홈 숫자, 목록 판정, 상세 문구가 전부 "두부는 갈 수 있어요" 식으로 바뀌는데, 이게 제일 좋았어요.
근데 필터에서 '실내 자리 필요' 한 번 눌렀더니 홈의 "두부가 갈 수 있는 곳"이 71곳에서 57곳으로 말도 없이 줄어 있었어요. 카페 소개 글이랑 판정이 서로 다른 말을 하는 곳도 두 군데 봐서, 숫자를 그대로 믿기가 좀 불안해요.

## 3. 가장 좋았던 점 3가지

1. **'두부 기준' 판정이 화면 곳곳에 일관되게 붙어요.** 홈 숫자, 목록 칩("갈 수 있어요 · 실내 OK"), 상세 제목("두부는 갈 수 있어요"), 근처 장소("두부에게 어려운 1곳은 뺐어요")까지 같은 말투예요. 등록 한 번으로 앱 전체가 내 앱이 되는 느낌이었어요.
2. **슬링백 유저를 배려한 문구가 있어요.** "케이지라고 적혀 있어요. 이동가방도 되는지 확인해 주세요", "3곳은 같은 이유예요 · …"처럼 왜 확인이 필요한지를 내 조건에 맞춰서 알려 줘요(13). 그냥 '확인 필요'만 띄우는 앱보다 훨씬 친절해요.
3. **저장에서 공유까지 흐름이 끊기지 않아요.** 하트를 누르면 토스트에서 바로 '저장한 곳 보기'로 가고, 저장 목록에서 지도, 길찾기, 일차 배정까지 한 화면에서 돼요. 상세에서 뒤로 가면 보던 지도(저장 3곳)로 정확히 돌아왔어요(26). '목록 공유'로 보낸 링크를 친구가 열면 "내 저장에 담기 3곳" 버튼 하나로 그대로 가져갈 수 있어요. 같이 여행 가는 친구랑 리스트 맞추기 딱 좋아요(37).

## 5. 총평

- **한 줄:** "두부 기준"으로 바꿔 주는 건 진짜 편한데, 필터 하나가 몰래 앱 전체 숫자를 바꾸고 소개 글과 판정이 엇갈리는 카페가 있어서, 결국 원문을 다시 열어 보게 돼요.
- **점수:** 7 / 10
- **다시 쓸 의향:** 조건부. 판정이랑 소개 글이 같은 말을 하고, 요일 같은 조건이 판정에 보이면 제주 가기 전에 홈 화면에 추가해 둘 것 같아요.

## 6. 평가 한계(못 본 것)

- Playwright Chromium으로 iPhone 13을 흉내 낸 거라 `navigator.share`가 없어요. 실제 iOS 공유 시트, 카카오톡 링크 미리보기 카드, 복사된 주소의 실제 도메인은 확인 못 했어요(복사된 건 평가용 localhost 주소예요).
- 평가 환경에서 서비스워커를 꺼 둬서 오프라인, '홈 화면에 추가하기'는 안 봤어요. 페이지마다 콘솔에 `Cannot read properties of undefined (reading 'waiting')` 오류가 찍혔는데, 화면에 드러난 영향은 없었어요.
- '가까운 순' 정렬, '내 위치로 이동'은 위치 권한이 필요해서 안 눌러 봤어요. 네이버 길찾기, 블로그 원문, 네이버 사진은 외부 링크라 열지 않았어요.
- 스크립트를 나눠 돌릴 때마다 브라우저를 새로 열었어요(localStorage는 이어지고 sessionStorage는 안 이어져요). 그래서 '어려운 곳 숨기기'가 풀린 건 "앱을 다시 열었을 때" 기준이에요. 같은 세션 안에서는 풀리지 않는다는 걸 따로 확인했어요(35).
- 평가 중에 '실내 자리 필요'를 켜 둔 상태로 저장·지도 과제를 했어요. 그래서 19·20번 스크린샷의 홈 숫자는 실내 기준 숫자예요.
- 전체 길이 캡처(fullPage)에서 탭바, 지도 버튼, 토스트가 본문 중간에 찍힌 건 캡처 방식 때문이라 버그로 안 쳤어요.
