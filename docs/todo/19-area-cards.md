## 0. 한 줄 요약

홈 「지역으로 찾기」(관광지 칩 27)를 **6권역 카드**로 바꾸고, 카드마다 "두부랑 **묵을 곳 n · 카페 n**"(홈 N 과 같은 셈)을 단다. 누르면 둘러보기가 그 권역·숙소 탭·'어려운 곳 숨기기' 로 열린다.
0칸은 '없다' 가 아니라 **'저희가 아직 덜 모았다'** 로 말한다. '추천' 이라는 말은 데이터 문턱을 넘은 칸에만(§4).

## 1. 지키는 것 (깨지면 조용히 틀린다)

- **셈은 홈 히어로와 같은 함수.** `countByLevel(그 권역의 placesOfType(type), dog, { needsIndoor })` 의 `ok + outdoor`. 히어로 N(`homePage.tsx`)이 종류별 이 값의 합이다.
  따로 세면 "홈은 12곳, 눌렀더니 11곳" 이 생긴다. **6권역 합 = 전체** 를 테스트로 묶는다(읍면이 매핑에서 빠지면 곳이 사라진다).
- **매핑은 둘이고 서로 맞아야 한다.** 장소는 `region.town`(읍면 13)만 갖는다 → 셈은 읍면 → 6권역. 관광지 칩을 어느 카드에 둘지는 `LANDMARKS_BY_AREA` 키(13, 우도 키 없음) → 6권역.
  같은 이름이 같은 권역으로 가는지 테스트가 잡는다(중문·서귀포·남원 → 남부, 한경 → 서부 …).
- **권역 조건은 비퍼시스트.** 읍면(`town`, 퍼시스트)이 카페 탭·다음 방문까지 새던 문제(ux-expert M-5) 때문에 홈은 퍼시스트 필터를 걸지 않는다(18 T2) — 권역도 관광지 검색어처럼.
- **식당은 카드 머리 숫자에 넣지 않는다.** 대부분 '확인이 필요해요' 인데 전화번호가 없다 — 세면 보증처럼 읽힌다. 둘러보기 식당 탭은 그대로라 길은 안 막힌다.
- **카드 0칸에 "없어요"·"추천" 을 쓰지 않는다.** 분모와 주어('저희가 모은')로 '모른다' 와 '어렵다' 를 가른다(§3 T4).

6권역(셈용 읍면 매핑):

| 권역 | 읍면 | 관광지 키 |
|---|---|---|
| 서부 | 애월읍 · 한림읍 · 한경면 | 애월 · 한림 · 한경 |
| 서남 | 대정읍 · 안덕면 | 대정 · 안덕 |
| 남부 | 서귀포시 · 남원읍 | 중문 · 서귀포 · 남원 |
| 동남 | 표선면 · 성산읍 | 표선 · 성산 |
| 동부 | 구좌읍 · 우도면 | 구좌 |
| 북부 | 조천읍 · 제주시 | 조천 · 제주시 |

권역 이름(화면)은 임시안 — "서부(애월·협재)" 처럼 아는 지명을 붙이는 쪽을 T4 에서 정한다.

- 홈 「지역으로 찾기」 = `screens/homePageLandmarkChips.tsx` — `LANDMARKS` 27개를 줄바꿈 칩으로, 누르면 검색어(`usePlacesPageFilterStore.setQuery`)를 걸고 `/places/stay`.
- 셈 = `lib/eligibilityCounts.ts` 의 `countByLevel`(`outdoor` 칸이 따로 있다, 14 W261007.5).
- 권역 키 = `lib/landmarks.ts` 의 `LANDMARKS_BY_AREA`(서쪽 애월부터 시계 방향 13키).
- 빈 상태 = 둘러보기의 0곳 안내(07 U3 다른 종류 수 · 18 T2.1 "읍면을 풀면 N곳").

## 4. 판정

| 무엇 | 언제 | 기준 |
|---|---|---|
| 데이터 문턱(T6 라벨) | 2026-10-22 첫 판정, 매주 `pnpm data coverage` | 소형견 숙소·카페 12칸 중 '갈 수 있어요(+야외)' ≥3곳 칸 6 → **10** · 다견 4 → **8** · 대형견 숙소 ≥2곳 권역 0/6 → **4/6**. 대형견은 숙소+카페 빈칸 ≤2/12 전엔 숫자만. **(+야외) 기준 실측(2026-10-08)은 소형 7 · 다견 5** — 6·4 는 야외를 뺀 값이다(T2 메모), 10-22 에는 7·5 와 견준다 |
| 정성 kill | 출하 뒤 주간 평가 2회(~2026-11-05) | 성호 ② · 하은 ② · 민지 ④⑥ · 준혁 ⑥ 중 카드에서 막힌 평가자 ≥2, 또는 0칸을 "제주엔 갈 곳이 없다" 로 읽은 평가자 ≥2/6 → 관광지 칩으로 되돌림 |
| 정량 go | 2026-12-03(모수 부족 시 12-31 한 번) — 애널리틱스를 들였을 때만 | 카드 → 둘러보기 진입 PV ÷ 홈 PV: <10% kill · ≥25% go(권역별 정적 페이지 · '숙소 없는 날 채우기'). 끝내 모수가 모자라면 유지·확장 안 함 |

합성 페르소나 평가는 kill 근거로만 쓴다 — go 는 진짜 사용자 수치가 있어야 한다.
