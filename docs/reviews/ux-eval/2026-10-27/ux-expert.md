# UX 전문가 평가 — 강아지랑 제주 (2026-10-27)

평가자: UX 전문가 페르소나(Nielsen 10 휴리스틱 + WCAG 2.2 AA 계측)
환경: Playwright `openApp({ device: 'iPhone 13' })`(390×664, ko-KR, 터치), 가로 누수만 iPhone SE(320)로 한 번 더 확인
스크린샷: `/tmp/ux-eval/2026-10-27/shots/ux-expert-*.png`(52장 촬영, 이 보고서에는 직접 열어 본 것만 인용)

## 1. 첫인상

화면 위계와 문장이 단정합니다. "갈 수 있어요 / 확인이 필요해요 / 이용하기 어려워요" 세 단어에 색과 이유 한 줄이 붙어 판정 결과를 이렇게 일관되게 말하는 앱은 드뭅니다. 기본기도 탄탄해서 reduced-motion, 포커스 이동, 스크롤 복원, 되돌리기가 거의 다 맞게 동작합니다. 다만 같은 장소를 '동쪽'으로도 '북부'로도 부르는 등 화면마다 용어가 갈리고, 필터 시트는 키보드로 다룰 때 포커스가 사라집니다. 겉의 정돈됨에 비해 이런 마감이 덜 됐습니다.

## 3. 가장 좋았던 점 3가지

1. **판정 문장이 일관되고 이유를 숨기지 않습니다.** 카드든 상세든 지도 시트든 「이용하기 어려워요」 아래에 「두부(7kg)는 5kg 이하 조건을 넘어요」 같은 이유 한 줄이 붙어 있습니다(shot 46). 식당 목록 맨 위의 「32곳은 같은 이유예요 · 케이지가 필요하다고 적혀 있어요 … 이동가방이 있으면 2곳은 '가능', 33곳은 '확인 필요'로 바뀌어요」는 휴리스틱 9(오류 진단)의 교과서 같은 사례입니다(shot 11).
2. **접근성 기본기가 상위권입니다.** 이름 없는 컨트롤이 0개이고, 지도 마커까지 「6곳 묶음: 식당 4곳, 카페 2곳. 눌러서 확대」라는 이름이 붙어 Tab으로 갈 수 있습니다. 건너뛰기 링크, 상세 진입 때 h1 포커스, 대화상자 포커스 가두기와 반환, reduced-motion 시 애니메이션 0개, 320폭에서 가로 누수 0까지 갖췄습니다.
3. **실수를 되돌리고 상태를 보여 줍니다(H3·H1).** 저장 비우기 뒤 「되돌리기」가 나오고, 저장 뒤에는 「저장했어요 · 저장한 곳 보기 ›」가, 등록 뒤에는 「두부 기준으로 바뀌었어요」가 뜹니다. 필터를 적용하면 「필터 1」과 「동쪽 ×」 칩이 남아 지금 무엇이 걸려 있는지 보이고, 검색 0건에는 「검색 지우기」와 제보로 가는 길이 있습니다.

## 6. 평가 한계(못 본 것)

- **스크린리더 실기기**(VoiceOver/TalkBack)는 쓰지 않았습니다. 접근성 이름과 역할은 Playwright ariaSnapshot으로만 확인했습니다.
- **지도 마커와 흐린 마커의 비텍스트 대비(1.4.11)는 수치로 재지 못했습니다.** 네이버 지도 캔버스 위라 배경이 일정하지 않습니다.
- **텍스트 확대(200%)와 시스템 글자 크기 변경**은 시험하지 않았습니다.
- **스와이프 제스처**(탭 사이 좌우 끌기, 시트 끌어내리기, 가장자리 뒤로가기)는 터치 드래그로 직접 해 보지 않았습니다. 대체 수단(탭·버튼)이 있다는 것만 확인했습니다.
- 전 페이지에서 `Cannot read properties of undefined (reading 'waiting')` 페이지 에러가 났습니다. 평가 하네스가 서비스워커를 막아서(`serviceWorkers: 'block'`) 생긴 것으로 보여 버그 목록에서 뺐습니다. 실제 기기에서 같은 에러가 나는지는 보지 못했습니다.
- 제보·「판정이 틀렸어요」 전송은 하네스가 성공으로 응답해, 실패했을 때의 메시지는 보지 못했습니다.
- 「두부」 한 마리(7kg·리드줄만)로만 판정을 봤습니다. 대형견, 여러 마리, 케이지 사용자 조합에서 판정이 일관되는지는 표본 밖입니다.
- 공유(Web Share), 내 위치, 네이버 외부 링크 도착 화면은 열지 않았습니다.
