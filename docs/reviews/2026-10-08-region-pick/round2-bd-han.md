# 2라운드 — 사업기획 한유진 (반박·수렴)

## 쟁점별 판정

**D1 화면 — 수정(강도윤 안 채택 + 조건 둘).** 가장 싸게 같은 가치를 내는 것은 강도윤 안이다. 홈 칩을 6권역 칩으로 바꾸고 개수를 단 뒤, 누르면 둘러보기 필터로 넘긴다. 새 로직은 `regionVerdictCounts` 하나다. 내 "숙소 먼저"는 새 화면 없이 두 조건으로 지킨다.
- 칩 표기는 "묵을 곳 n · 카페 n" 순서로 쓴다.
- 칩을 누르면 둘러보기가 **숙소 탭**으로 열린다.

서지원의 「동네」 화면은 go 이후로 미룬다. 그때 권역별 정적 페이지로 만들어 검색 유입·공개 리포트에 쓴다.

**D2 숙소 먼저 — 앞에 세우는 것은 유지, 식당은 양보.** 소형견도 식당 '갈 수 있어요'가 34곳 중 3곳이다(강도윤). 전화번호도 없어서 '물어보면 갈 수도' 칸은 보증처럼 읽힌다. 식당은 칩에서 빼고 둘러보기에만 둔다.

**D3 0칸 — 수정.** "아직 없어요"는 여전히 '없다'를 단정한다. 강도윤 말이 맞다. 해법은 **분모를 보여 주는 것**이다. 분모가 있으면 시장의 빈칸과 우리 수집의 빈칸이 갈린다.
- 모아 둔 곳이 2곳 이하일 때(모른다): "중문·서귀포 쪽은 보리랑 묵을 곳을 **아직 1곳밖에 모으지 못했어요**. 가까운 대정·안덕 쪽엔 1곳 있어요 · 아는 곳 알려 주기"
- 모아 둔 곳은 충분한데 갈 수 있는 곳이 적을 때(어렵다): "모아 둔 숙소 9곳 중 보리가 갈 수 있는 곳은 1곳이에요"(서부)

6권역 숙소·카페엔 분모 0인 칸이 지금 없어, 빈칸은 전부 이 둘 중 하나다. 뒤의 문장은 "15kg 이상은 10곳 중 1곳"이라는 시장 현실을 그대로 보여 준다.

**D4 순서 — 수정(병행하되 운영자 손은 숙소에 몬다).** 화면은 코드 시간이라 검수와 경쟁하지 않는다. 병목인 운영자 손을 강도윤의 8~11시간에서 **약 6시간으로 줄인다.**
1. 신규 숙소 48곳 검수(2.5~4시간). 숙소 0인 권역(성산·한림·남원·서귀포)과 대형견 후보부터 본다.
2. **숙소·카페만** 전화번호를 단다(약 1.5시간).
3. 시간이 남으면 카페 39곳을 검수한다.

식당 번호는 미룬다.

**D5 측정 — 확인 완료. 측정은 "확장"의 선결 조건이지 "칩 변경"의 선결 조건은 아니다.** Vercel 공식 문서로 둘 다 확인했다.
- Hobby는 비상업 전용이다. 광고는 상업 이용이다. 제휴 링크는 "사이트의 주목적일 때" 상업 이용이라 회색 지대다.
- 사용자 정의 이벤트는 Pro부터다. Hobby는 월 5만 이벤트이고, 넘으면 수집이 멈춘다.

칩 변경은 비용 0이라 정량 없이 유지해도 된다(강도윤). 하지만 합성 페르소나는 kill 근거뿐이라, 다음 투자(「동네」 페이지·숙소 빈날 채우기)의 go 는 **정량 없이 판정할 수 없다.**

가장 싼 길은 **Vercel Web Analytics Hobby의 페이지뷰만** 쓰는 것이다.
- 비용 0원. 우리 쪽 런타임 쓰기도 0이다(같은 출처의 Vercel 수집점).
- 권역 진입은 별도 정적 경로 6개로 센다. 쿼리가 집계되는지는 미확인이다.
- 숙소 상세는 원래 `/place/:id` 경로라 그대로 센다.
- 외부 클릭은 재지 않는다.
- 단, ADR-015 결정 2 를 고치는 짧은 ADR 과 오너 결정이 먼저다(서지원·강도윤).

**D6 BM — 같은 트랙이다. 강도윤의 정의를 채택한다.** 서지원의 질문에 답하면, 12개월 안에 돈이나 지원에 닿는 것은 **공백 표 → 데이터 협업** 쪽이다. 이유는 둘이다.
- 제휴 링크는 우리 숙소 26곳에 OTA 링크가 0개다.
- 월 1만 방문이어도 6.5만 원 수준이다.

`pnpm data coverage` 를 돌린 출력이 곧 B2G 공백 표이자 공개 리포트의 원본이 된다.

**제휴 링크는 다섯 조건을 모두 채울 때만** 단다.
1. 숙소 상세 페이지뷰가 월 5천 이상
2. OTA 등록률 50% 이상
3. Pro 로 전환
4. "순서는 판정과 거리로만 정한다"는 규칙을 ADR 로 남기고 화면에도 공개
5. 공정위 기준에 맞는 제휴 표시

링크는 상세 화면에만, 네이버 버튼과 같은 모양으로 단다. 목록엔 링크가 없으니 수수료가 순서에 닿을 길이 없다(강도윤 "증명" 질문의 답).

손익만 보면 Pro 연 약 34만 원을 메우는 데 예약이 연 28건 필요하다(건당 1.2만 원). 빨라도 2027 하반기다.

**D7 기획명 — 「두부랑 갈 동네」로 양보.** D2 에서 범위가 숙소와 카페로 정해졌으니 「묵을」은 너무 좁다. 「갈」은 판정 문구 "갈 수 있어요"와 같은 말이다. 서지원의 "두부랑 어디 갈까요?"는 그 줄의 안내 문구로 쓴다.

## 상대에게 인정하는 것

- **서지원**: 저장이 0인 첫 방문자에게는 들어올 입구가 없다. 그리고 홈 N 과 권역 개수는 **같은 함수**로 세야 한다. 기획의 존재 이유이자 불변식이다.
- **강도윤**: 0곳은 '없다'가 아니라 '모른다'다. 그리고 우리가 넘길 수 있는 자산은 블로그 원문이 아니라 스키마·엔진·정답셋이다. 내 1라운드의 "데이터 자산"은 저작권을 고려하지 않은 표현이었다.

## 합친 최종안

**단기 2주**
1. `regionVerdictCounts` 를 만들고 3-2 표를 테스트로 고정한다. 홈 N 과 같은 함수를 쓴다.
2. 홈 칩을 6권역 칩으로 바꾼다.
   - 표기는 "묵을 곳 · 카페" 개수. 식당은 뺀다.
   - 0칸 문장은 분모로 '모른다'와 '어렵다'를 가른다.
   - 누르면 둘러보기 숙소 탭이 권역 필터와 숨기기를 켠 채 열린다. '추천' 라벨은 붙이지 않는다.
3. `pnpm data coverage` 를 매주 돌리고, 첫 판정은 10-22 에 한다.
4. 운영자는 약 6시간을 쓴다: 숙소 48곳 → 숙소·카페 전화번호 → 카페.
5. 애널리틱스 ADR 은 오너가 30분 들여 결정한다.

**중기 BM**: ⑦ 관광공사 대조군과 coverage 공백 표로 2027 공모전, 제주도·혼저옵서개 협업, 연간 공개 리포트를 준비한다. 제휴는 다섯 조건을 채울 때까지 보류한다.

**go/kill**: 데이터 문턱(강도윤 표)을 넘은 칸에만 '추천' 라벨을 켠다. 12-03 에 권역 진입 페이지뷰를 홈 페이지뷰로 나눠 본다.
- 10% 미만이면 kill(칩만 유지).
- 25% 이상이면 go(「동네」 정적 페이지와 숙소 빈날 채우기).
- 모수가 부족하면 12-31 로 한 번만 미룬다.
