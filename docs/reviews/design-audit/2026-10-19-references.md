## 2. 지배적 패턴 (직접 본 것만 센다)

### Q1. 숙소·식당·카페 같은 형제 종류 전환

- 같은 화면에서 형제 종류를 바꾸는 컨트롤은 직접 본 곳 **1곳**(NOL 목록) — **글자 탭 + 브랜드 글자색 + 2px 밑줄**, h44, 굵기 고정, 헤더 밑·필터 줄 위.
- 최상위 전환은 대부분 홈 아이콘 타일 → 별도 페이지(4곳). 세그먼트를 쓰는 곳(에어비앤비·마이리얼트립)은 **중립·검정**이다.
- 종류를 필터 칩 하나로 넣는 곳 2곳(캐치테이블 `브런치`, 에어비앤비 `펜션`).
- **브랜드 틴트 알약 세그먼트로 종류를 바꾸는 곳은 0곳.**

### Q2. 필터

- 진입점은 직접 본 4/4 가 **검색창 바로 밑 가로 칩 줄 + 맨 앞(또는 옆) 필터 버튼 + 정렬 ▾**. 칩은 알약, h34~40, 12~14px/**400**, 옅은 회색 1px 테두리 또는 회색 면.
- 켠 칩을 **브랜드 단색으로 채운 곳 0/4** — 브랜드 테두리 + 옅은 틴트(NOL·캐치테이블) 또는 회색을 진하게 + 굵게(네이버).
- 켠 필터 수는 **필터 버튼 한 곳**(숫자 배지 또는 점).
- 시트는 4/4 가 굵은 섹션 제목 + 구분선, 알약은 줄바꿈. 데이터 성격대로 컨트롤을 섞는다(불리언 = 토글, 긴 목록 = 체크박스, 배타 = 세그먼트).
- **옵션마다 개수 0/4** — 개수는 결과 버튼에 한 번(3/4).
- 푸터 4/4 가 왼쪽 `초기화`(글자·테두리) + 오른쪽 넓은 주 버튼.

### Q3. 길찾기 / 다른 지도 앱으로

- **지도 회사가 아닌 3/3 은 목록 카드에 길찾기가 없다.** 지도 회사(네이버 구형·카카오)도 카드엔 **회색 글자 칸·테두리 분할 버튼**이지 채운 버튼이 아니다.
- 상세는 지도 회사가 아닌 2/2 가 지도 → 주소(+복사) → **중립 테두리 버튼**(흰 면 · 회색 1px · r10). 브랜드 채움은 예약 같은 주 행동 몫.
- 네이버·카카오로 넘기는 직접 증거는 캐치테이블 1곳 — 브랜드 신호는 **앱 아이콘에만**, 버튼 색도 ↗ 도 아니다. 길찾기에 ↗ 를 붙인 곳 0곳.

## 3. 한계

- 여기어때 목록·필터·상세, BringFido 는 Cloudflare 에 막혔다. 반려동물 서비스는 직접 본 곳이 0(반려생활은 스토어 스크린샷만).
- 네이버 m.place 상세·목록은 CAPTCHA — 통합검색 플레이스 블록에서 본 것이라 네이버 지도 앱과 다를 수 있다.
- 직접 본 서비스 8곳. N/M 은 경향이지 통계가 아니다.
