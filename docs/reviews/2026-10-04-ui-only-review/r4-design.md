# 디자인 크리틱: 반려견 동반 제주 가이드 앱

**확인 범위:** 아래 화면은 직접 열어 봤습니다. 상태 B 화면은 폴더에 없습니다. 둘러보기 목록의 full 캡처(A-02, C-02)는 너무 작게 줄어 카드 세부를 읽지 못했습니다. 목록 카드는 C-03 보이는 화면으로 판단했습니다. A-04, C-04, A-07, A-08, C-08, A-12, C-11은 열지 않았습니다.

## 화면별 한 줄 메모
- A-01-home-full: 짱구누나의 긴 인사 카드가 홈의 가장 큰 덩어리고, 이 앱의 핵심인 "강아지 등록"은 그 아래 작은 카드에 있음.
- C-01-home-full: 히어로 문구가 "두부랑 제주 어디 갈까요?"로 바뀌고 카테고리에 "가능 21 · 확인 0"이 붙어 개인화가 바로 느껴짐. 식당은 "가능 3 · 확인 31"이라 쓸 만한 곳이 거의 없어 보임.
- A-02-places-stay-full / C-02-places-stay-full: 카드 틀은 같고 C에서 판정 배지가 붙음. 카드 수가 많아 길게 이어짐.
- C-03 (A-03과 같은 틀): 카드 구조가 일관됨. 설명은 두 줄에서 "…"로 잘림. 이름·읍면·태그 위계는 좋음.
- A-05-map: 마커가 겹치고 필터 칩 3개가 모두 같은 마젠타라 카테고리 색 구분이 사라짐. 상단 오버레이가 엄지에서 멀리 있음.
- A-06-detail-stay-full: 가격이 준비물 칩 아래로 밀려 있고, 위치 지도는 "불러오는 중"에 멈춰 있음.
- C-06-detail-stay-full: "두부는 갈 수 있어요" 판정이 생겼지만 같은 정보(1~5kg 1만원)가 세 번 반복됨.
- C-07-detail-restaurant-full: "야외만"이라는 조건부 판정이 갈색 점으로만 구분됨. 지도는 이 화면에서만 제대로 뜸.
- C-13-detail-stay2-full: 가격이 "3만원"으로 한 번, "1마리당 3만원"으로 또 나옴. 지도는 다시 로딩 상태.
- A-09 / C-09-checklist: 아코디언과 진행 막대가 깔끔함. C에서 "숙소에 있어요" 연동은 좋은 디테일.
- A-10-saved-full: 빈 상태가 제 역할을 다함(아이콘, 한 줄 설명, CTA).
- C-10-saved-full: 저장 카드가 상세의 요약판으로 잘 정리됨. "메모 남기기"가 카드 밖에 떠 있음.
- A-11-settings-full: 정돈됐지만 비어 있음. "우리 강아지 등록하기"가 홈과 같은 문구로 중복됨.
- C-12-dog-full: 라디오 선택지는 명확함. 저장 버튼이 하단 탭에 반쯤 가려 있음.
- C-14-places-filter-sheet: 읍면별 건수가 붙은 칩이 좋고 CTA "26곳 보기"가 엄지 영역에 있음. 맨 아래 항목이 잘림.
- C-15-map-marker-sheet: 바텀시트 + "자세히 보기 / 저장"의 하단 배치가 이상적임.
- C-16-detail-report-sheet: 선택지가 큼직하고 "답장은 못 드려요"를 솔직히 말해 신뢰를 줌.

## 1. 한 줄 총평
**"갈 수 있어요"를 내 강아지 기준으로 바로 판정해 주는 점이 확실한 무기인 따뜻한 앱입니다. 그런데 그 판정과 등록 유도가 화면에서 가장 크게 보이지 않고, 인사말과 반복 문구에 묻혀 있습니다.**

## 3. 지킬 것 3
1. **판정 문장 "두부는 갈 수 있어요"와 "가능 / 확인" 카운트.** A에서 C로 갈 때 화면이 확실히 달라져 보상이 분명함.
2. **카테고리 3색(파랑·주황·초록)과 아이콘 타일.** 홈, 목록, 저장, 근처 카드까지 같은 규칙으로 일관됨.
3. **하단 시트 패턴과 솔직한 문구.** 필터, 마커, 제보 시트가 모두 같은 문법이고 CTA가 아래에 있음. 빈 상태와 제보 안내 문구도 사람 말투라 브랜드가 살아 있음.

## 4. 바꿀 것 3 (심한 순)
1. **핵심 정보의 위계.**
   - 홈에서는 등록 유도(핵심 기능)가 인사 카드보다 약함. 등록 카드를 위로 올리거나 인사 카드를 한두 줄로 줄이세요.
   - 상세(C-06 등)에서는 판정이 작은 점과 얇은 글씨고, 설명·준비물 칩이 먼저 눈에 옵니다. 숙소는 가격도 준비물 아래로 밀립니다.
   - 판정을 상단 배지나 색 띠로 키우고 가격을 준비물보다 위로 올리세요.
2. **반복과 의미가 겹치는 색.**
   - 같은 정보가 반복됩니다. 상세에서 "1~5kg 1만원"이 칩, 본문, 판정에 세 번 나오고, "정보는 바뀔 수 있어요"는 상세마다 반복됩니다. 홈과 준비물 상단의 "아무래도 강아지랑…" 문구도 똑같이 나옵니다.
   - 마젠타 한 색이 활성 탭, CTA, 하트, "갈 수 있어요", 지도 칩 전부에 쓰입니다. 가능=초록, 조건부=주황, 확인 필요=회색처럼 판정 전용 색을 분리하세요.
3. **미완성 느낌의 디테일.**
   - 지도가 "불러오는 중이에요"에서 멈춰 있음(C-06, C-13).
   - 준비물 이모지가 라인 아이콘과 따로 놂.
   - 지도 칩 3개가 같은 색이라 마커 색과 대응되지 않음.
   - 강아지 폼의 저장 버튼이 하단 탭과 겹침.
   - 쿠팡 고지문이 작음(약 11px).
   - 목록 설명이 "…"로 잘림.

## 6. 다른 관점의 리뷰어라면 놓칠 것 1
식당 목록의 "가능 3 · 확인 31"은 카피나 개발 관점으로는 정직한 표기지만, 디자인 관점에서는 쓸 수 없는 화면입니다. 두부 같은 소형견 사용자가 식당 탭에서 거의 모든 카드에 노란 "확인이 필요해요"를 보게 되고, 그러면 판정 기능 자체가 약해 보입니다. "확인이 필요해요"를 단일 경고색으로 반복하지 말고 이유(전화 확인, 케이지 필요 등)를 보여 주거나 정렬로 내려야 합니다.
