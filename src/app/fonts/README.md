# 나눔스퀘어 네오 (NanumSquare Neo)

- 배포: 네이버 — https://campaign.naver.com/nanumsquare_neo/
- 라이선스: **나눔글꼴 라이선스** — 개인·기업 상관없이 무료로 사용·재배포할 수 있고,
  글꼴 파일을 유료로 판매하는 것만 금지한다. 웹서비스 임베딩과 이 레포에 포함해 배포하는 것은 허용된다.
- 여기 있는 `.woff2` 는 원본 TTF 를 **서브셋한 파생본**이다(한글 완성형 11,172자 + 라틴).
  변형 자체도 라이선스가 허용하며, 출처 표시로 이 파일을 함께 둔다.
