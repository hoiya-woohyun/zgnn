# 14. 주간 사용성 평가 — 회차별 개선 태스크

> 최종 수정: 2026-10-06 (v1: 신설 — 회차가 아직 없다. `/ux-eval` 이 돌 때마다 맨 위에 `## <날짜> 회차` 를 더한다)

매주 한 번 페르소나 6명이 앱을 써 본 결과([docs/reviews/ux-eval/](../reviews/ux-eval/README.md))에서 나온 개선 태스크.
회차가 이 파일 하나에 쌓인다 — 주마다 파일을 새로 만들지 않는다.

## 규약

- 태스크 ID 는 `W<YYMMDD>.N`(회차 날짜 + 영향 순번). 실행 규약은 [08](08-usability-and-process-plan.md) 그대로 — 한 태스크 = 한 커밋.
- 기존 07·08·10·11·12 에 같은 태스크가 있으면 체크박스 대신 `↪ <기존 ID>` 로 적는다(중복 태스크 금지).
- 다음 회차 종합이 "해소됨" 으로 판정한 태스크는 `[x]` 로 닫고 그 회차 날짜를 붙인다. 여러 회차째 반복되는 지적은 줄 끝에 `반복 N회`.
