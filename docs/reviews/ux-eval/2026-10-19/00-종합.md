## 2. 페르소나별 고유 발견

- **민지(3kg·슬링백·카페)** — 상세 저장은 토스트가 없다(목록 하트만). 탭바에 '저장' 이 없어 토스트를 놓치면 홈 '내 여행' 까지 내려간다. 카드 하나가 커 한 화면에 1.5~2장. 홈 "71곳" 시트에 종류 건너뛰기가 없어 카페는 35곳 아래. 첫 화면 절반이 짱구누나 편지, 등록 예시가 숙소뿐.
- **성호(30kg·리드줄)** — **'판정이 틀렸어요' 가 빈 채로 전송된다**(무엇이 틀렸는지 고르는 칸이 없는데 입력은 "한 줄 더(선택)"). '야외 2'(머리글)와 '확인 필요 · 야외만'(카드)이 다른 뜻이라는 걸 한참 뒤에 알았고, 야외 배지가 확인 필요와 같은 주황 계열. 객실 조건은 본 숙소 9곳 중 먼슬리브 한 곳뿐(.11 칸은 섰고 데이터가 비었다). 호텔 핀코 근처에 '갈 수 있어요' 식당 0곳(가장 가까운 확정은 10km) — 이유는 "30곳은 같은 이유예요 · 케이지 필수라 대형견은 어려워요" 로 납득. 목록 "9월 확인" 에 연도가 없다.
- **영자(62세·SE)** — **카드의 판정 알약이 화면에서 가장 작은 글씨(12px · 연한 바탕)**. 지도 '내 위치' 가 상세 '길찾기' 와 같은 종이비행기라 길찾기로 알았다. '길찾기' 는 출발지 빈 네이버 '빠른길찾기' + 광고(반복 2회). 콩이 5kg 에 기내용 가방 "5kg 이하/이상" 둘 다(반복 2회), 준비물에 콩이 이름이 없고 유모차도 똑같이 나온다. '판정'·'원문'·'쿠팡 파트너스'·'노션' 을 모른다. "9월 확인" 이 9월에 가라는 건지 헷갈린다. 위치를 부산으로 주면 "273km" 에 확인 필요 집이 맨 위.
- **준혁(2.5kg+12kg·유모차·4인)** — 유모차로 식당 47곳 중 **35곳 '확인 필요'**(32곳이 "케이지라고 적혀 있어요. 유모차도 되는지 확인해 주세요"), 케이지로 바꾸면 가능 6 → 38 — 정직하지만 "식당 탭이 전화 목록". **웨스티하우스 "해피만 데려가면 갈 수 있어요" 인데 콩만도 된다**(반복 2회 — `dogSubsetWhatIf` 가 같은 수면 무거운 아이를 고르는 규칙). 캄 "2마리 합계 4만원 또는 7만원" — 두 금액을 늘어놓을 뿐 왜 둘인지 안 말한다. 몸무게를 바꾼 뒤 '어려움' 으로 간 곳이 접힘 속으로 사라진다. 그리너리빌리지는 걸리는 이유 둘 중 하나만 말한다. 홈 준비물 줄은 저장이 생겨야 뜬다. 토스트 "콩과 해피" ↔ 홈 "콩이와 해피". 사람 인원 필터·'이번 여행엔' 토글·준비물 마리 수는 반복.
- **하은(서귀포 현지인·검색부터)** — **앱이 쓰는 말 '서귀포 시내' 로 검색하면 0곳**(홈 카드 "남부(서귀포 시내·남원)"), '법환'·'강정' 0곳인데 "가게를 알려 주세요". '중문' 결과에 중문에서의 거리가 없다. 검색 결과 첫 화면은 안내 줄이 쌓여 첫 카드가 바닥. 지도 시트가 누른 마커를 덮고, '내 위치' 는 500m 까지 들어가 카페 1곳, 섬 전체(묶음 원)에선 흐림 안내가 없고 '야외만' 마커가 '가능' 과 같은 모양. 장소 제안 뒤 화면이 그대로라 또 누를 것 같다. '정보가 달라요' 토스트가 확인 문구를 가린다. 상세 미니 지도가 너무 확대돼 동네 이름이 안 보인다(주소 없는 서울앵무새는 그게 유일한 단서). 데스크톱은 필터가 첫 화면 절반·지도 패널에 고른 가게가 두 번(반복 3회). 홈·지도에 검색창이 없다(반복 2회). 오기 "700명 규모 정원"(반복 3회).
- **UX 전문가(계측)** — 25kg 으로 바꾸면 숙소 21 → 6 인데 **카페·식당 수는 7kg 과 한 자리도 안 바뀐다** — 크기 언급 없는 곳(오늘당근 "실내외 모두 가능")도 근거 표시 없이 '갈 수 있어요', 숙소는 같은 경우 cond(기준이 비대칭 — 10-13 성호의 백화stay ↔ 소금바치순이네와 같은 결). 예방접종 조건 5곳(무히어·언더라운지·솔옆수·일기초록·스프레무따)은 프로필에 답할 칸이 없어 영원히 '확인 필요'. 스테이다랑쉬 "두부(7kg)는 7kg 이하까지 여유가 없어요" + '갈 수 있어요' — 거절로 읽힌다(I2 의 0kg). 키보드: 뒤로 오면 포커스가 body(들어갈 땐 h1 — .14b), 홈을 스크롤하면 h1 접근 이름이 빈 값·히어로 버튼이 트리에서 사라짐. 지도 h1 둘, 판정 점이 이름 없는 img, 준비물 접근 이름 "방한용품겨울", 이동 수단 라디오 빈 원 1.29:1(.14f 밖), 200kg 이 경고 없이 통과, 설정 0곳일 때 회색인데 눌림. 요금 문구 형식 셋(반복 2회). 지역을 '동부'/'동쪽'/'동쪽 구좌읍' 셋으로 부른다. 근처 '더 보기' 의 '숙소/식당/카페' 링크 24×44, 동네 카드 장소명 링크 24~36×44(밑줄 없음).

## 3. 바꾸지 말 것 (전원 또는 다수가 칭찬)

- **이름·숫자로 말하는 판정 + 원문, 모르는 건 "적혀 있지 않아요"** — "보리(30kg)는 7kg 미만 조건을 넘어요" · "받아 준다면 보리는 5만원" · "1박 기준인지는 적혀 있지 않아요". 6/6. 성호 "지금까지 써 본 것 중 최고".
- **등록 한 번에 앱 전체가 그 아이 기준 + 바뀐 수 토스트**("57 → 70곳" · "57 → 56곳" · "두부 기준으로 바꿨어요 · 71곳"). 6/6.
- **어려운 곳을 숨기지 않고 '어려움 N곳 보기' 로 접어 이유와 함께** · 근처 "어려운 2곳은 뺐어요 · 함께 보기". 성호·준혁·전문가.
- **"N곳은 같은 이유예요 · 이동가방이 있으면 …" + '우리 강아지 정보 고치기'** — 하은이 바꿔 보니 예고대로 바뀌었다. 하은·성호·준혁·전문가(숫자 표현은 #3 으로 고친다 — 패턴은 그대로).
- **두 마리 합계 요금 + "합계인지 1마리당인지 적혀 있지 않아요"**. 준혁 "엑셀을 안 켜도 되겠다".
- **저장 → 메모·일차·지도·목록 공유 → 친구의 '내 저장에 담기'**. 민지·준혁.
- **다른 종류로 넘기는 검색 · '서귀포' 시내/읍면 나눔 · 0곳에서 바로 제안(검색어 미리 채움)**. 하은·민지.

- **숫자 정합성과 접근성 기본기** — 히어로 68 = 21 + 11 + 36 · 야외 13 = 6 + 7(25kg 도), reduced-motion 애니메이션 0 · skip link · 포커스 링 · 시트 포커스 가두기·Esc 복귀 · 가로 누수 0 · 텍스트 대비 AA 미달 0 · 24px 미만 터치 0. 전문가.
