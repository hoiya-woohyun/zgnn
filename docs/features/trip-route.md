# 하루 동선 — 날짜로 묶고, 순서를 정하고, 네이버로 넘긴다

> 최종 수정: 2026-10-08 (v1: 신설 — 순수 함수와 한 곳짜리 길찾기가 들어갔다. 저장 화면의 하루 보기·묶음 판정 줄은 **임시안**(자리·문구는
> 디자인 트랙 [10 §7](../todo/10-user-feedback-personas.md) 이 다시 정할 수 있다) · 경유지 주소는 폰 실측 전)

왜 이런 모양인지(Directions API 를 안 들이는 이유, 앱 스킴 대신 웹 주소)는 [ADR-026](../decisions/ADR-026-route-ours-navigation-naver.md),
태스크·🙋·실측 항목은 [todo/16](../todo/16-trip-route-planner.md).

## 사용자가 하는 것

1. 저장한 곳마다 **1일 · 2일 · 3일 · 4일 · 미정** 중 하나를 고른다(기본 미정).
2. 하루를 열면 **순서 제안**이 나온다 — 시작점에서 가까운 순으로 잇고 숙소로 끝난다. 끌어 바꿀 수 있고, "순서 다시 제안" 으로만 되돌아간다.
3. 하루 머리에 **묶음 판정 한 줄**("콩이·보리 둘 다 갈 수 있어요" / "이 날은 콩이만"), 걸린 곳 옆에 같은 종류·같은 읍면의 "대신 △△".
4. **길찾기**를 누르면 그 날 순서가 경유지로 실린 네이버 지도 길찾기가 열린다. 7곳 이상이면 6곳씩 알약이 나뉜다.
5. 장소 하나는 일정과 무관하게 **길찾기** 한 번 — 저장 카드 · 상세 액션 줄 · 지도 시트. 출발은 현재 위치(네이버가 채운다).

| 무엇 | 어디 |
|---|---|
| 날짜 라벨·손 순서 | `lib/tripPlan.ts` · 스토어 `tripDays` · `tripOrder` |
| 시작점·순서 제안 | `lib/tripRoute.ts`(`suggestOrder`) · 하루 보기 재료 `lib/tripDayView.ts` |
| 묶음 판정·대안 | `lib/tripEligibility.ts` · `lib/tripAlternatives.ts` |
| 네이버 주소 | 한 곳 `lib/naverPlaceLink.ts`(`naverDirectionsUrl`) · 여러 곳 `lib/naverRouteLink.ts`(`splitStops` → `routeUrl`) |

## 비직관적인 것

- **일정은 저장의 부분집합이다.** 하트를 지우면 날짜 라벨도 순서도 같이 빠진다. 저장하지 않은 곳을 일정에 넣는 길은 없다 —
  두면 "저장" 의 뜻이 둘로 갈린다(ADR-026 결정 1). 준비물도 그래서 날짜를 모른다.
- **시작점 기본값은 1일차 공항, 2일차부터 전날 숙소**(16 🙋2 권고). "전날" 은 곳이 있는 가장 가까운 앞 날이다 — 2일차를 비우고 3일차를 짰으면 1일차 숙소에서.
  앞 날에 곳은 있는데 숙소가 없으면 출발점이 없다(공항에 다시 내린 게 아니다). "내 위치에서" 는 누를 때 한 번 받고 저장하지 않는다.
- **순서는 직선거리다.** 섬 하나라 순서를 정하기엔 충분하지만 시간·차로 거리는 아니다. 소요 시간은 화면에 없다 — 네이버로 넘어가야 보인다.
- **사용자가 손댄 날은 자동 제안이 덮지 않는다.** 라벨을 바꿔 그 날에 곳이 늘면 손 순서 뒤에 붙는다.
- **길찾기 묶음은 이어진다.** 두 번째 알약의 출발은 첫 알약의 도착이다 — 비워 두면 미리 열어 본 두 번째 링크가 지금 자리에서 출발한다.
- **좌표가 없는 곳(86곳 중 5곳)은 길찾기 주소에서 빠지고** "지도에 없는 N곳" 으로 따로 말한다. 손 순서 가운데 있어도 뺀다.
- **묶음 판정의 '정보 없음' 은 실패가 아니다.** 장소 하나에선 '확인된 정보가 없어요' 가 조합을 막지만, 묶음에선 막지 않는다 — 막으면 그런 곳이
  한 곳만 끼어도 "이 날은 콩이만" 을 못 한다(16 T2.1 메모). 대안은 '갈 수 있어요' 인 곳만이다 — '확인이 필요해요' 로 바꾸는 건 대안이 아니다.
- **영업시간·휴무 충돌은 보지 않는다.** 데이터가 없다(16 🙋3). 판정은 반려동물 조건까지다.
- ⚠️ **경유지 주소의 꼴은 폰에서 확인 전이다**(16 H.1). 구분자 `:` · 상한 5 가 틀리면 `naverRouteLink.ts` 의 두 상수만 고친다.
  한 곳짜리 주소는 경유 칸이 `-` 라 이 문제와 무관하다.

## 하지 않는 것

Directions API·자체 내비·소요 시간 · 저장하지 않은 곳을 일정에 · 날짜별 준비물 · 카카오내비·티맵 · 일정 공유(16 🙋4 — 다음 트랙).
