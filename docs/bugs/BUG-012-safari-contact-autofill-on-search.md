# BUG-012 — 둘러보기 검색칸을 누르면 Safari 가 내 연락처를 자동완성으로 띄웠다

> 최종 수정: 2026-10-07 (v1: 신설)
> 상태: 고침(`src/components/noAutofill.ts` — 자동완성이 뜰 자리가 아닌 입력칸 전부에 펼친다).

## 증상

둘러보기 검색칸("이름·특징·읍면 검색")을 누르면 Safari 키보드 위에 **연락처 자동완성**(내 이름·전화)이 떴다. 강아지 등록의 이름 칸(라벨 "이름")도
같은 자리였다. 검색어·강아지 이름에 내 연락처가 들어갈 일은 없다.

## 원인

입력칸에 자동완성 관련 속성이 하나도 없었다(`components/base/input` 은 Untitled UI 복사본이라 기본값이 없다). Safari 는 칸의 **`name` → 자리표시 글자 → 라벨**
순으로 훑어 "이름"·"주소"·"전화" 같은 말이 보이면 연락처 카드를 띄운다 — 자리표시 글자의 "이름" 이 그대로 걸렸다. 그리고 이 훑기에서는
**`autocomplete="off"` 를 무시한다**(Apple 개발자 포럼 thread 764041 등). 그래서 `off` 한 줄로는 Chrome 만 고쳐진다.

## 고침

- `NO_AUTOFILL` = `name="search_nofill"` + `autoComplete="off"`. Safari 의 훑기는 `name` 에 `search` 가 있으면 거기서 멈추므로 자리표시 글자·라벨까지 내려가지 않는다.
  정적 앱이라 폼을 보내지 않고 `name` 으로 칸을 찾는 코드도 없어, 같은 `name` 이 여러 칸에 있어도 무해하다.
- `SEARCH_FIELD` = 위 + 자동 고침·첫 글자 대문자·맞춤법 끔 + `enterKeyHint="search"`. 가게 이름·지명이 사전 낱말로 고쳐지지 않게.
- 붙인 곳: 둘러보기 검색, 강아지 이름·몸무게, 저장 메모, 제보 메모(textarea), `/admin` 의 검색·메모·장소 고치기 칸 전부.
  **로그인 칸은 뺐다** — 거기서는 자동완성(`username`·`current-password`)이 도와야 한다.

## 남는 것

- 새 입력칸을 만들면 `{...NO_AUTOFILL}`(검색이면 `SEARCH_FIELD`)을 펼친다. 빠져도 빌드·테스트는 통과하고 Safari 에서만 드러난다.
- Safari 의 휴리스틱은 문서화돼 있지 않아 버전마다 바뀔 수 있다. 다시 뜨면 실기기에서 `name` 을 바꿔 가며 본다.
