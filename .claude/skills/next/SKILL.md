# /next — 대기열 이어 가기

사용자는 다음 할 일을 매번 고르지 않는다. **판단은 내가 하고, 사람이 꼭 필요한 일만 「기다림」 에 모은다.**
대기열은 `docs/todo/NOW.md` 하나다. 번호 붙은 todo 문서(00~15)는 **명세**이고, NOW.md 는 그중 지금 할 것의 **순서**다.

## NOW.md 의 세 칸

```md
## 지금 (위에서부터)
- [ ] <한 줄 제목> — [14 W261006.1](14-weekly-ux-eval.md) · 왜 지금: <한 마디>

## 기다림 (사람 손·결정)
- 🙋 <정할 것> — [링크] · 권고: <내 권고 한 줄>
- 🧑 <사람이 해야 하는 일> — [링크] · 명령: `<사용자가 칠 것>`

## 발견 (분류 전)
- <작업 중 찾은 것 한 줄> — 출처: <커밋/파일>
```

- 「지금」 은 **5~10개**. 에이전트가 레포 안에서 끝낼 수 있는 일만(사용자 로그인·원격 DB 쓰기·큰 구독 한도·법적 판단이 필요하면 「기다림」).
- 순서 기준: 판정이 틀리는 것(핵심 가치) > 데이터가 틀리는 것 > 막힌 흐름 > 다듬기. 같은 급이면 작은 것 먼저.

## 실행 순서

1. **잡기** — NOW.md 를 직접 골라 읽지 말고 `node .claude/skills/next/claim.mjs take` 로 한 줄을 **선점**한다(아래 「여러 세션에서 동시에」).
   - `CLAIMED n/m <줄>` · `RESUME n/m <줄>`(이 터미널이 전에 잡고 못 끝낸 줄) → 그 줄이 내 일이다. 맨 위가 아니어도 그 줄을 한다.
   - `NONE …` → 「지금」 이 비었으면 4 의 정리부터, 전부 다른 세션이 잡았으면 5 의 보고로 멈춘다(남의 줄을 하지 않는다).
2. **한 일 하기** — 잡은 줄의 링크(명세)를 열어 그 태스크 절만 읽는다.
   - 시작할 때 한 줄: `▶ <제목> (<링크>)`.
   - 명세가 낡았으면(코드가 이미 그렇다·전제가 바뀌었다) 고치지 말고 명세에 `> 메모:` 로 사실을 적고 닫거나 다시 쓴다.
   - 구현은 CLAUDE.md 의 위임 규칙대로(여러 파일 → executor, 판단이 큰 설계 → opus). 프론트 편집 순서·owner-prefix·문서 갱신 정책을 지킨다.
   - 검증: 관련 테스트 + `pnpm tsc --noEmit -p .`, 화면이 바뀌면 Chrome 확장으로 한 번(Playwright 는 확장이 안 될 때만 — CLAUDE.md 「작성 규칙」).
   - **줄 지우기** — 커밋 직전에 `node .claude/skills/next/claim.mjs done`. 잠금 안에서 NOW.md 의 내 줄을 지우고 선점을 푼다
     (완료 기록은 명세와 git 에 있다 — NOW 에 쌓지 않는다). Edit 로 지우지 않는다 — 다른 세션이 같은 파일을 동시에 고친다.
   - **커밋** — 경로를 지정해 `git add`(다른 세션의 변경을 섞지 않는다). 명세의 `[ ]` → `[x]` + `> 메모:` 한 줄, 그리고 `docs/todo/NOW.md` 를 같은 커밋에.
   - 사람을 기다리게 돼 못 끝내면 그 줄을 「기다림」 으로 옮기기 **전에** `claim.mjs release` 로 선점을 푼다.
3. **발견 적기** — 하다가 찾은 버그·개선점은 고치지 말고(범위가 번진다) 「발견」 에 한 줄. 단 지금 일을 끝내려면 꼭 필요한 한 줄 수정은 그 커밋에.
4. **다음으로 / 멈추기** — 아래 중 하나면 멈추고, 아니면 1 로(다시 `take` — 그사이 다른 세션이 다음 줄을 잡았을 수 있다).
   - 이 세션에서 3개를 끝냈다 · `[컨텍스트 NNNk]` 알림을 받았다 · 다음 일이 사람을 기다린다 · `take` 가 `NONE` 이다.
   - 멈추기 전에 **정리**(`claim.mjs list` 로 🔒 줄을 먼저 본다 — **남이 잡은 줄은 고치거나 옮기거나 순서를 바꾸지 않는다**. 제목(` — ` 앞)이 바뀌면 그 세션의 선점이 풀린다): 「발견」 을 명세 문서(맞는 번호 문서, 없으면 14 처럼 가장 가까운 곳)에 `[ ]` 태스크로 옮기고, 지금 할 만하면 「지금」 에 순서대로 끼운다. 사람이 필요하면 「기다림」. NOW.md 를 커밋한다.
5. **보고** — 짧게: 끝낸 것(커밋 해시) · 「기다림」 에 새로 생긴 것(사용자가 할 일, 명령 포함) · 다음 맨 위 항목. 끝 줄은 `→ /clear 후 /next` .

## 여러 세션에서 동시에

사용자는 같은 작업 트리(develop)에서 세션 2~3개로 `/next` 를 친다. **친 순서대로 서로 다른 줄**을 맡아야 한다 —
NOW.md 를 각자 읽고 "맨 위" 를 고르면 읽기와 잡기 사이의 틈에서 셋이 같은 줄을 잡는다. `claim.mjs` 가 그 틈을 없앤다:

- 잡기는 `mkdir` 잠금 안에서 "아무도 안 잡은 첫 줄" 을 고른다 — 먼저 친 세션이 위 줄을 받는다.
- 주인은 터미널의 claude 프로세스(`CLAUDE_PID`)다. 터미널을 닫으면 선점이 저절로 풀리고, `/clear` 뒤 같은 터미널의 `/next` 는 하던 줄을 `RESUME` 으로 돌려받는다.
- 기록은 `.claude/next-claims.json`(git 밖). 사용자가 선점을 손으로 풀고 싶으면 그 파일을 지우면 된다.
- 레지스트리 밖에서 잡아 둔 줄은 제목 맨 앞에 `🔒` 를 적는다 — `take` 가 건너뛴다. 되도록 줄을 넣는 세션도 `take` 로 잡는다.
- 다른 세션이 이미 잡은 줄의 파일을 내 일 때문에 고쳐야 하면 고치지 말고 「발견」 에 적는다(같은 파일 동시 편집 금지).
- 다른 세션이 cross-session 메시지로 "N번을 맡았다" 고 알려 와도 정본은 `claim.mjs list` 다.

## 하지 않는 것

- 「지금」 이 남았는데 "다음에 뭘 할까요?" 라고 묻지 않는다. 권고가 있으면 「기다림」 에 권고와 함께 적고 다음 일로 간다.
- 원격 DB 쓰기·`supabase db push`·`pnpm data …` 의 큰 실행(수십 번의 `claude -p`)·push 는 하지 않는다 → 「기다림」 에 명령과 함께.
- NOW.md 를 다시 140줄로 키우지 않는다. 명세는 번호 문서에.
