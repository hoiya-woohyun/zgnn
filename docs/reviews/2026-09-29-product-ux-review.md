## 0. 한 줄 요약

**판정 엔진은 잘 만들어졌는데, 판정이 가장 자주 내놓는 답이 "확인이 필요해요" 이고 앱은 그다음 행동을 주지 않는다.**
그리고 2주 동안 만든 것(수집·분석·검수·재빌드)은 **장소 수**를 늘리는 쪽이지 이 구멍을 메우는 쪽이 아니다.

## 2. 판정이 실제로 내놓는 답 (86곳 × 강아지 5종, `needsIndoor=false`)

| 강아지 | 숙소 (26) | 식당 (34) | 카페 (26) |
|---|---|---|---|
| 말티푸 4kg · 이동 수단 없음 | 가능 21 · 정보없음 5 | 가능 3 · 확인 3 · **어려움 28** | 가능 22 · 확인 4 |
| 말티푸 4kg · 이동가방 | 가능 21 · 정보없음 5 | 가능 3 · **확인 31** | 가능 22 · 확인 4 |
| 푸들 7kg · 유모차 | 가능 18 · 어려움 3 · 정보없음 5 | 가능 3 · **확인 31** | 가능 23 · 확인 3 |
| 웰시코기 15kg · 없음 | 가능 9 · 어려움 12 · 정보없음 5 | 가능 3 · 확인 3 · 어려움 28 | 가능 22 · 확인 4 |
| 대형 2마리 28+17kg · 없음 | 가능 4 · 확인 3 · 어려움 14 · 정보없음 5 | **가능 0** · 확인 6 · 어려움 28 | 가능 3 · **확인 23** |

읽는 법:
- **식당은 이동 수단 하나로 결판난다.** 가방이 없으면 28곳이 "어려움", 있으면 31곳이 "확인". 즉 식당 탭에서 판정은 거의 정보를 더하지 않고,
  사용자가 실제로 알아야 할 것은 "가방을 챙기면 28곳이 열린다" 와 "그 31곳에 전화해 보라" 다.
- **대형견 보호자에게 앱은 "제외 목록" 이다.** 식당 0 · 카페 3 이 "가능", 나머지 대부분이 "확인". 9/15 리뷰의 민준 평("제외용으로는 믿음") 그대로다.
- 숙소 "정보 없음 5" 는 어떤 강아지에게나 같다 — 데이터 보강 한 번으로 다섯 줄이 사라진다.

## 3. 화면별

| # | 화면 | 관찰 | 심각도 |
|---|---|---|---|
| U1 | 상세 | "확인이 필요해요" 카드 아래에 **전화 버튼이 없다.** 순서도 판정 → 원문 → **준비물 넛지** → 네이버 버튼이라 행동 버튼이 한 화면 아래로 밀린다 | P0 |
| U2 | 홈 | 인사말 카드가 첫 화면의 약 1/3 을 매번 차지한다(재방문에도). 프로필 등록 CTA 는 흰 카드 한 줄이라 가장 중요한 행동이 가장 약하다. 등록 뒤에도 첫 화면에 "보리와 콩이 갈 수 있는 곳" 이 요약되지 않고 종류 카드의 `7/26` 로만 보인다 | P1 |
| U3 | 둘러보기 | 검색어·방향·조건·"어려운 곳 숨기기" 가 **탭을 바꾸면 초기화**된다(`placesPage.tsx` 의 `useState` — 읍면만 스토어라 유지). "애월" 치고 카페로 넘기면 26곳이 다시 뜬다. 검색이 종류 안에서만 돈다 | P1 |
| U4 | 판정 문구 | 솔숲펜션("1~5kg 1만원 / 6~10kg 1.5만원")에서 28kg 에게 "대형견 언급이 없어요" 라고 말한다. 요금표 상한이 10kg 라는 사실이 더 쓸모 있는 근거다(등급은 그대로 `cond`, 문구만) | P2 |
| U5 | 목록 배지 | 요금 배지가 첫 구간만 보인다("1~5kg 1만원") — 28kg 보호자에게 그 배지는 틀린 정보처럼 읽힌다 | P2 |
| U6 | 준비물 | 아무것도 체크 안 했는데 "8가지 중 **1가지 준비됐어요**" — 저장한 숙소의 구비품을 준비됨으로 센다. "1가지는 숙소에 있어요" 로 따로 말해야 한다 | P2 |
| U7 | 지도 | 판정 색 마커는 있지만 **"어려운 곳 숨기기"** 가 지도에는 없다(목록에만). 대형견 보호자가 동쪽 39곳을 하나씩 눌러야 하는 9/15 지적이 절반만 풀렸다. *실측 못 함 — 코드 기준* | P2 |
| U8 | 데이터 표기 | 읍면이 `서귀포`(1)와 `서귀포시`(6)로 갈려 필터 칩이 둘로 나뉜다 | P2 |
| U9 | PWA | 설치 안내가 없다(`beforeinstallprompt`·"홈 화면에 추가" 0건). iOS 는 사용자가 방법을 알아야 설치된다 | P2 |
| U10 | 데스크톱 | 목록 1열 · 읍면 칩 줄이 오른쪽에서 잘림 · 정렬 셀렉트가 혼자 한 줄 | P3 |

## 4. 잘 되고 있는 것 (건드리지 않는다)

- 판정 → 이름 넣은 요금 줄("보리와 콩이는 6만원 (1마리당 3만원)") — 이 앱만 할 수 있는 한 줄이다.
- 판정순 정렬(가능이 위로), 필터 시트의 "우리 강아지 기준" 묶음, 저장 → 준비물 파생.
- 원문 병기와 "어려움" 이라는 말투 — 단정하지 않는 태도가 신뢰의 바탕이다.
- 오프라인 지도 안내 카드("연결이 없어도 저장한 곳과 목록은 그대로") — 실패 화면이 다음 행동을 준다. **U1 이 이 태도를 상세에도 가져와야 한다는 얘기다.**
