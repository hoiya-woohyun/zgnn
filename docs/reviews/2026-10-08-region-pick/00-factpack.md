# 사실 묶음 — "오늘 가고 싶은 지역" 기획 토론용 (2026-10-08)

> ⚠️ 정정(토론 뒤): §2 표의 "읍면 칩 — 홈 종류 카드" 는 틀렸다. 홈에는 읍면 칩이 이미 없고(18 T2), **관광지 칩 27개**
> (「지역으로 찾기」, `homePageLandmarkChips.tsx` — 누르면 검색어로 `/places/stay`)가 있다. 읍면(퍼시스트)은 둘러보기에만 남았다.
> 페르소나들의 "홈 읍면 칩을 6권역 칩으로" 는 "관광지 칩 줄을 6권역 묶음으로" 로 읽는다 — 결론 문서 §4 「사회자 판정」.
> 또 `LANDMARKS_BY_AREA` 의 권역 키는 14 가 아니라 **13**(우도 키가 없다)이고, 장소는 그 키가 아니라 `region.town`(읍면 13)만 갖는다 — §3-2 의 6권역 셈은 읍면으로 했다.

이 문서 하나가 토론의 공통 근거다. 레포를 다시 훑지 말고 이걸 근거로 말한다(필요하면 인용된 파일 한두 개만 확인).

## 0. 사용자(제품 오너)의 원문

> 오늘 가고싶은 지역이라는 기획을 할거야. 아직 정확한 기획명은 생각하지 못했고, 가제로 일단 진행할게. 좋은 제목 있다면 추천해줘.
> 사용자가 오늘 방문하고 싶은 지역을 몇개를 고르게 할게.
> 그리고 나면, 해당 지역으로 가는 길에 있는 카페를 경유한다던가 하는 식의 기획을 하려했는데 생각보다 별로인 것 같아.
> 반려동물을 키운다면 카페를 특정짓고 아마도 떠날것 같다는 생각도 들고..
> 아니면 괜찮다는 생각이 드는게, 여행에서 가고 싶은 곳을 고르면, 애견과 같이 묵을수 있는 숙소와 카페를 일자별로 추천해주던가, 일자 기능까지 과하다 싶으면 지역별로 추천해주는 정도는 할 수 있을 것 같은데...
> 이게 괜찮은건지 경쟁력이 있는건지, 다른쪽에서 이미하고 있는것은 아닌지.. 판단할 수 없는 요소가 많으니 기획자·사업기획 페르소나로 BM 을 설계할 중기 관점 및 당장 프로젝트에 진행할 단기 관점으로 토론해 최적의 결론을 내 달라.

## 1. 제품 한 줄 · 제약

- **강아지랑 제주(zgnn)**: 반려견 동반 제주 가이드 PWA. 핵심은 **내 강아지 조건(몸무게·마릿수·이동수단) × 장소 이용 조건 → 판정 4단계**(갈 수 있어요 / 확인이 필요해요 / 확인된 정보가 없어요 / 이용하기 어려워요). 판정 근거 원문을 하이라이트해 같이 보여준다.
- 원 자료는 작성자 "짱구누나"(제품 오너의 배우자)가 Notion 에 정리한 가이드. 말투는 친근한 존댓말. 20~30대 여성 취향 톤(핑크+크림).
- 운영자 = 제품 오너 부부 둘. **사이드 프로젝트**. 수익 모델 없음.
- 기술 제약
  - Next 16 **정적 내보내기 — 서버 없음**. 데이터는 빌드 시점 JSON. 원본은 Supabase, 승인하면 재빌드로 반영(ADR-015).
  - 사이트가 런타임에 쓰는 곳은 **장소 제보 insert 하나뿐**(ADR-021).
  - **회원·로그인 없음**. 사용자 상태(강아지 프로필·저장·일정)는 기기 localStorage 에만. 회원·로그인은 "추후 고도화" 로 todo 에서도 빼 둔 상태(ADR-011·012 는 제안 단계).
  - **장소 사진 없음**(타인 블로그 저작권, ADR-002). 종류 색+아이콘이 대신한다. 네이버 플레이스 사진은 링크로 보낸다.
  - 지도는 네이버(NCP Maps). **비용 = 지도를 띄운 방문 수**(ADR-008). Directions(경로) API 는 **들이지 않는다** — 경로 짜기는 우리, 운전 안내는 네이버 웹 길찾기 URL(경유 ≤5)로 넘긴다(ADR-026).
  - 데이터 파이프라인: 네이버 블로그 수집 → Claude(구독, `claude -p`)가 이용 조건 구조화 → 운영자가 `/admin` 에서 검수·승인. 사람 검수 시간이 병목.
  - **분석 도구(애널리틱스) 없음** — 방문·클릭 수를 지금은 아무것도 못 잰다.

### 3-2. 판정을 걸면 — 6개 큰 권역 × 강아지 유형 (실제 `judgeEligibility` 로 계산)

권역: 서부(애월·한림·한경) · 서남(대정·안덕) · 남부(서귀포·중문·남원) · 동남(표선·성산) · 동부(구좌·우도) · 북부(조천·제주시).
셀 = **갈 수 있어요 / +야외 자리만 / +확인이 필요해요 / 전체**. s=숙소 r=식당 c=카페.

**두부 3kg · 가방(소형견 1마리 — 가장 유리한 조건)**
```
서부  s 8/0/0/9   r 2/0/7/9   c 2/1/0/3
서남  s 3/0/0/4   r 0/0/0/0   c 4/0/0/4
남부  s 0/0/1/1   r 1/0/7/8   c 1/0/0/1
동남  s 2/0/0/2   r 0/1/4/5   c 5/0/0/5
동부  s 5/0/1/8   r 0/0/6/6   c 8/1/0/9
북부  s 2/0/0/2   r 0/0/6/6   c 1/0/1/2
```
**보리 30kg · 이동수단 없음(대형견)**
```
서부  s 1/0/0/9   r 0/0/2/9   c 0/0/3/3
서남  s 1/0/0/4   r 0/0/0/0   c 1/0/3/4
남부  s 0/0/0/1   r 0/0/1/8   c 1/0/0/1
동남  s 0/0/1/2   r 0/0/2/5   c 1/0/4/5
동부  s 1/0/2/8   r 0/0/0/6   c 0/1/8/9
북부  s 1/0/1/2   r 0/1/0/6   c 0/0/2/2
```
**콩 2.5kg + 해피 12kg · 유모차(다견)**
```
서부  s 3/0/0/9   r 2/0/7/9   c 2/1/0/3
서남  s 1/0/0/4   r 0/0/0/0   c 4/0/0/4
남부  s 0/0/0/1   r 1/0/7/8   c 1/0/0/1
동남  s 1/0/0/2   r 0/1/4/5   c 5/0/0/5
동부  s 1/0/2/8   r 0/0/6/6   c 8/1/0/9
북부  s 2/0/0/2   r 0/0/6/6   c 1/0/1/2
```
읽는 법:
- 6개 **큰** 권역으로 묶어도, 대형견은 권역마다 '갈 수 있는 숙소' 0~1곳, **'갈 수 있는 식당'은 전 권역 0곳**이다.
- 소형견도 남부(중문·서귀포)는 '갈 수 있는 숙소' 0곳. 식당은 대부분 '확인이 필요해요'(전화로 물어야 함).
- 읍면 단위(사용자가 실제로 고를 단위)로 쪼개면 빈칸이 더 많다.
