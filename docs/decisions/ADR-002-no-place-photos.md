# ADR-002: 장소 사진을 쓰지 않는다

> 작성일: 2026-09-15
> 상태: 채택

## 맥락 (Context)

- 원 자료의 장소 86곳에는 후기 링크가 있고, 처음엔 그 블로그에서 사진을 내려받아 카드·상세에 쓰려 했다.
- 확인 결과 후기 86개 중 **85개가 작성자가 아닌 다른 블로거의 글**이었다. 한 번 내려받았다가 전부 삭제했다.
- 준비물 이미지는 Notion `attachment:` URI 라 서명 URL 없이는 받을 수 없다.

## 결정 (Decision)

- 사진 없는 화면을 **기본 디자인**으로 삼는다. 사진 자리는 종류 색 워시 + 종류 아이콘이 대신하고, 이름·읍면·특징 문장이 화면을 이끈다.
- `scripts/fetch-blog-images.mjs` 는 `OWN_BLOG_IDS` 허용목록(기본 비어 있음)만 받는다. 타인 블로그를 다시 받지 않는다.
- `TPlace.cover` / `images` 필드와 읽는 코드는 남긴다. 작성자 본인 사진이 생기면 데이터만 채워 사진이 나오게 한다.

## 결과 (Consequences)

- 종류 색이 종류를 가르는 **유일한 시각 신호**가 됐다. 브랜드 색에 흡수시키지 않고 별도 토큰으로 유지한다(→ [ADR-003](./ADR-003-untitled-ui-and-palette.md)).
- 장소 상세 헤더는 사진 대신 타입 색 파스텔 워시 판이다(`src/screens/placeDetailHeader.tsx`).
- 이미지 런타임 캐시 규칙은 `src/app/sw.ts` 에 남아 있지만 지금은 걸릴 요청이 없다.
