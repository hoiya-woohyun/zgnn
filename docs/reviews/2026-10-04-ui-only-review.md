## 0. 한 줄 요약

**넷 모두 "우리 강아지 기준으로 갈 수 있나를 한 문장으로 답한다" 를 이 앱의 존재 이유로 꼽았다 — 그런데 그 답이 가장 자주 "확인이 필요해요" 이고,
언제 확인한 정보인지 보이지 않아 강점이 깎인다.** 09-29 리뷰의 한 줄 요약과 같은 자리다. 전화번호·제보를 넣은 뒤에도, 문서를 모르는 눈에는 아직 그렇게 보인다.

## 1. 방법 — 왜 이렇게 했나

**AI 페르소나는 같은 문서를 읽으면 같은 결론으로 모인다**(10-01 의 세 사람이 서로 다른 이유로 모두 "제보할 곳이 없다" 에 닿았다).
그리고 이 레포는 문서가 촘촘해서, 리뷰어가 ADR 을 읽으면 "사진이 없는 건 저작권 때문" 같은 사정을 알고 들어가 사용자가 느낄 의문을 스스로 덮는다.
그래서 독립성을 만드는 장치를 넷 넣었다.

| 장치 | 어떻게 |
|---|---|
| 맥락 차단 | 리뷰어는 레포 밖 폴더에서 `claude -p --restricted --strict-mcp-config` 로 돌렸다 — 프로젝트 `CLAUDE.md`·설정·훅·플러그인이 안 실리고, 파일 도구가 그 폴더에 갇힌다. 실행 전 Haiku 로 "맥락에 '강아지랑 제주'·ADR 이 있나" 를 물어 **없음**을 확인했다. Agent 도구 서브에이전트는 프로젝트 `CLAUDE.md` 를 물려받으므로 쓰지 않았다 |
| 입력 분리 | ① 앱을 직접 조작(독립 Playwright MCP `--isolated`, 7kg 비숑 보호자) ② 상태 A·B 스크린샷 + 웹 검색 ③ 전체 48장 ④ 상태 A·C |
| 모델 분리 | ① Sonnet ② Haiku ③ Opus ④ Sonnet — 브라우저 조작은 Haiku 가 헤매면 "앱이 헷갈린다" 로 섞여 들어가 Sonnet 에 줬다 |
| 출력 강제 | 같은 점수표 6칸 + 지킬 것 3 / 바꿀 것 3 / 다음 하나 + **"다른 관점이라면 놓칠 것 1"** |

- 촬영: dev 서버(`:7727`) 390×844, 상태 A(입력 없음) · B(28·17kg 2마리, 이동 수단 없음) · C(3.2kg 이동가방, 3곳 저장) × 주요 화면 + 필터 시트·지도 마커 시트·제보 시트. Next dev 표시는 CSS 로 가렸다. 설명·사정은 목록에 적지 않았다.
- 오염 검사: 결과물에서 `ADR|C7|eligibility|src/|petPolicy|BUG-` 0건. 다만 이건 뒷받침일 뿐이고, 격리는 위 실행 방식이 맡는다.
- **실제 사람이 아니다.** 07 P0 / 08 H.1 의 실제 5명 테스트는 여전히 대체되지 않는다.

## 5. 의도한 결정과 부딪힌 지적

문서를 모르는 눈이라서 보이는 것 — 결정을 유지하더라도 "이 결정이 사용자에게 이렇게 보인다" 는 정보다.

- **확인 날짜가 없다(③②)** — 결정이 아니라 **만들었는데 안 보이는** 경우다. `placeDetailFreshness.tsx` 는 이미 날짜를 그리는데 `places.json` 에 `verifiedAt` 이 있는 곳이 **0곳**이라 예전 문구("바뀔 수 있어요")로 떨어진다.
  [todo/10](../todo/10-user-feedback-personas.md) 의 확인일 마이그레이션이 원격 미적용(🧑 H.1)인 것과 맞물린다(추정 — 원격 상태는 이 리뷰에서 확인하지 않았다).
- **사진이 없다** — 넷 중 아무도 문제로 꼽지 않았다(② 의 비교표에 "사진 풍부" 가 경쟁 앱 쪽 칸으로만 나온다). [ADR-002](../decisions/ADR-002-no-place-photos.md) 의 결정이 화면에서 무리 없이 받아들여진다는 신호다.
- **사용자 후기·평점이 없다(②)** — [ADR-021](../decisions/ADR-021-place-reports.md) 은 '다녀왔어요' 를 받되 건수를 공개하지 않기로 했다. 신뢰 점수 2 의 이유 중 하나로 꼽혔다.
- **제주만 다룬다(② 의 "다음 하나" = 전국 확대)** — 제품 범위 자체와 부딪힌다. 참고로만 둔다.

## 8. 다시 돌릴 때

- 지시문·촬영 목록·출력 형식은 [prompts/](./2026-10-04-ui-only-review/prompts/) 그대로 쓴다. 지시문에 앱 내부 용어(판정·이용 조건·확인 필요)를 넣지 않는다 — 넣으면 리뷰어가 그 틀로 본다.
- 촬영은 **전체 캡처 전에 끝까지 스크롤**하거나, 지연 로딩 영역을 따로 찍는다(§7 첫 줄).
- 상태를 localStorage 로 넣을 때는 저장소 값의 실제 표기(`'여름'`)를 쓴다(§7 셋째 줄).
- Playwright MCP 의 `--blocked-origins` 는 **출처 단위**다 — `http://localhost:7727/admin` 을 넣으면 앱 전체가 막힌다(첫 실행이 그래서 실패했다). `/admin` 은 지시문으로만 막았다.
- 화면 판독이 중요한 자리에 Haiku 를 두지 않는다(§2 ⚠️).
