## 왜 월 1회·주제 하나인가

- 경쟁 앱은 주 단위로 바뀌지 않는다. 매주 돌리면 같은 보고서가 나온다.
- 한 번에 전부 보면 "온보딩도 지도도 상세도" 가 한 줄씩 얕게 남는다. 주제 하나를 깊게 보고 넉 달에 한 바퀴 돈다.
- 스토어 페이지는 클라우드 환경에서 직접 열리지 않는다(egress). 근거는 **웹 검색에 인용된 스토어 설명·후기·공개 소스**다 — 보고서에 그 한계를 적는다.
- 우리 앱은 **코드만** 보고 파악한다(기획 문서 금지). 기획 문서는 평가를 의도 쪽으로 수렴시킨다 — 주간 사용성 평가와 같은 원칙.

반려생활 · 댕기자 · 델고 · 펫패스(PetPass) · BringFido. 새로 눈에 띄는 앱이 있으면 하나를 바꾸고 "지난달과 달라진 것" 에 적는다.
