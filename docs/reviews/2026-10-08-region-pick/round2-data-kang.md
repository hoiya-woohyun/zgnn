# 2라운드 — 강도윤(데이터·리서치)

## D1 화면 — **양보**

- 서지원의 「동네」 하위 화면을 받아들입니다.
- 둘러보기 흡수로도 W261007.12·.9 는 풀리지만, 칩은 한 권역씩이라 **권역끼리 비교가 안 됩니다.** "어디로 갈까"는 6장을 나란히 놓아야 답이 됩니다.
- 서지원의 kill 조건("둘러보기랑 뭐가 달라요?" 3/6 이상이면 흡수)도 받습니다.

## D2 숙소 먼저 — **수정**

- 순서는 숙소 → 카페 → 식당(접힘)입니다. 한유진 말대로 대형견은 숙소가 지역을 정합니다(6권역을 합쳐 4곳뿐입니다). 숙소 데이터는 법 개정의 영향도 적습니다.
- 식당을 "범위 밖"으로 빼자던 주장은 철회합니다. 대신 접힌 **"물어봐야 알아요 N"** 칸으로 둡니다.
  - 머리 숫자(홈 N 과 같은 셈: 갈 수 있어요 + 야외)에는 넣지 않습니다.
  - 사유 한 줄과 확인일을 붙입니다.
- 서지원 질문에 답하면, 이 조건이면 신뢰를 깎지 않습니다. 넣을 사유의 선은 `coverage` 에 `primaryReason` 별 개수를 더해 다음 주에 긋습니다.

## D3 0칸 — **수정**

가까운 권역 대안(서지원)과 숨기지 않기(한유진)는 둘 다 받습니다. 그래도 문장의 주어가 '동네'이면 "없다"고 단정하게 됩니다. 주어를 **'저희가 모은 곳'** 으로 바꿉니다.

> 「저희가 모은 {n}곳 중엔 아직 {두부}랑 갈 수 있는 곳이 없어요. 아는 곳이 있으면 알려 주세요」

- 뒤에 "가까운 대정·안덕 쪽엔 1곳" · 장소 제안(ADR-021).
- n=0 이면 「이 동네는 아직 저희가 모은 곳이 없어요」로 씁니다.

## D4 순서 — **양보·유지**

- **화면 먼저에 양보합니다.** 소형·다견의 빈칸이 1/12 이하라는 출시 문턱은 이미 넘었습니다.
- 우선순위표는 화면이 아니라 **같은 함수**에서 나옵니다. 1주차에 `areaCounts` 와 `pnpm data coverage` 를 만들고 검수를 시작합니다. 2주차에 화면을 냅니다.
- **대형견 게이트는 유지합니다.** 빈칸이 2/12 이하가 될 때까지는 숫자만 보여 줍니다.
- "칸당 3곳" 은 게이트가 아니라 검수 목표로 내립니다.

## D5 측정 — **유지 (2주 안에는 정량 측정 없음)**

- 2주 안에는 결정 하나만 합니다(🙋): 쿠키 없이 같은 출처에서 페이지뷰만 세는 ADR 을 둘지입니다. 이건 ADR-015 결정 2 를 깨는 일이고, Hobby 약관은 아직 확인하지 않았습니다. 구현은 출하한 뒤에 합니다.
- 커스텀 이벤트 대신 화면을 별도 경로로 둡니다.
- 한유진 질문에 답합니다. 외부 클릭률 5% 와 15% 를 가르려면 10%±5% 의 95% 구간이 필요합니다.
  - 숙소 상세 진입이 **약 140회** 필요하고, 홈 세션으로 따지면 약 2,300회입니다.
  - 지역 진입 200회로는 상세 진입이 60회(±7.6%p)라 가르지 못합니다.
  - 비수기 편향은 같은 주 안의 비율만 봐서 피합니다.
  - n 이 모자라면 기본값은 **유지·확장 안 함**입니다.

## D6 BM — **같은 트랙, 하나만 유지**

- 한유진의 A+B 와 내 안(⑦·제주도 협업·리포트)은 같은 트랙입니다.
- 하나는 유지합니다. 라이선스에서 **근거 원문은 뺍니다.** 블로그 원문은 남의 것이라, 넘길 수 있는 것은 구조화한 조건·확인일·정정 이력입니다.
- 지역 기능이 보태는 것: 권역×크기 **공백 표**(B2G 제출물)와 공모전용 **사용 지표의 입구**.
- OTA 대조는 검수와 시간이 겹쳐 미룹니다.

## D7 기획명 — 「두부랑 어디 갈까요?」

존댓말 질문이라 판정을 단정하지 않고, 카페 투어가 목적인 민지도 밀어내지 않습니다. "숙소 먼저"는 카드 순서가 말하게 합니다.

## 인정하는 것

- **서지원**: 홈 N 과 같은 함수·0670182 의 야외 셈으로 세자는 것("12곳 → 눌렀더니 11곳" 방지).
- **한유진**: 숙소 26곳 OTA 링크 0·네이버 예약 제휴 없음이라는 실측 — 수수료 공식이 깨집니다.

## 합친 최종안

**단기 2주**
- **1주차** — `AREA_GROUPS`(14→6) 와 `areaCounts` 를 만듭니다. 홈 N 과 같은 함수로 세고, §3-2 표를 테스트로 고정합니다. `pnpm data coverage` 도 같은 함수를 씁니다. 운영자는 숙소가 0곳인 권역(남부·동남)의 숙소부터, 이어서 신규 숙소 48·카페 39 를 검수합니다.
- **2주차** — 「두부랑 어디 갈까요?」를 냅니다.
  - 들어오는 곳: 홈 N · 지역 칩 · 저장이 빈 상태
  - 6권역 카드 안의 순서: 숙소 → 카페 → 식당(접힘)
  - 0칸 문장, `nearestAreaWith`, 날짜 칩
  - W261007.12·.9 를 닫고, 측정 ADR 을 결정합니다.
- **운영자 손: 약 7~10.5h** — 검수 4.5~7.5h · 데이터 묶음 1h · 전화번호 1.5~2h(07 P0 를 열 경우).

**중기 BM** — B2G·2027 공모전(⑦ 이 먼저)과 공백 표·연간 리포트, 원문을 뺀 판정 데이터셋. 제휴는 보류합니다.
